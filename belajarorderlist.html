Mata Pelajaran Konsentrasi Keahlian

  • Rekayasa Perangkat Lunak
    RPL (Rekayasa Perangkat Lunak) adalah jurusan yang fokus mempelajari cara merancang, mengembangkan, dan memelihara perangkat lunak alias software
    1. DDPK
    2. Pemrograman Web
    3. Basis Data
    4. Pemrograma Berbasis Text
    5. Pemrograman Perangkat Bergerak
  • Desain Komunikasi Visual
    DKV (Desain Komunikasi Visual) adalah cabang dari ilmu desain yang mempelajari konsep komunikasi dan ungkapan kreatif, teknik dan media dengan memanfaatkan elemen visual ataupun rupa, untuk menyampaikan pesan tujuan tertentu.
    1. DDPK
    2. Fotografi
    3. Vidiografi
    4. Editing
    5. Desain
  • Akuntansi
    AKL (Akuntansi dan Keuangan Lembaga) adalah jurusan di SMK yang fokus mempelajari pengelolaan keuangan, pencatatan transaksi, laporan keuangan, serta administrasi perbankan dan lembaga keuangan.
    1. DDPK
    2. Akuntansi Biaya
    3. perpajakan
    4. manajemen keuangan
    5. aplikasi perangkat lunak akuntansi
  • Perhotelan
    Perhotelan merupakan program pendidikan tinggi yang mempersiapkan mahasiswa untuk bekerja di industri perhotelan dan pariwisata
    1. DDPK
    2. manajemen operasional hotel
    3. pelayanan tamu
    4. table manner
    5. kasir
HTML
HTML adalah singkatan dari HyperText Markup Language, bahasa markup standar untuk membuat dan menyusun halaman web.
CSS
CSS adalah singkatan dari Cascading Style Sheets, yaitu bahasa yang digunakan untuk mengatur tampilan dan desain halaman web.
PHP
PHP adalah singkatan dari PHP: Hypertext Preprocessor, yaitu bahasa pemrograman yang banyak digunakan untuk membuat website dinamis.
